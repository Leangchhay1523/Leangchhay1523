### 🔬 Distilling Multimodal Foundation Models into Lightweight OCR for Low-Resource Khmer

**Presented — ASEAN Conference on Emerging Technologies (ACET 2026), CADT Innovation Center, Nov 12, 2026**

Built a Khmer OCR dataset of educational textbook pages with transcriptions from a multimodal model (Gemini), then distilled that knowledge into a smaller OCR-focused vision-language model by fine-tuning **DeepSeek-OCR-2** with **LoRA**.

**Research Highlights**

- **Response-based knowledge distillation** for Khmer OCR, using **Gemini 3 Flash Preview** as the teacher
- **15,876-page** dataset of Khmer textbook pages (100 human-verified) and a **393-image multi-font benchmark**
- Evaluation with **CER/WER** on human-verified pages and an external multi-font benchmark
- Released the dataset, LoRA adapter, and code for non-commercial research

**Technologies**

Python · Gemini · DeepSeek-OCR-2 · Unsloth · LoRA · Knowledge Distillation · OCR Evaluation
